# HomePrint — установщики

HomePrint — домашняя лаборатория печати для рисунков: скан → обработка → макет → печать, с настройкой сканера и принтера под вашу бумагу. Интерфейс на русском.

Код программы закрыт, здесь лежат только установщики и обновления.

## Установка

1. Откройте [последний релиз](../../releases/latest) и скачайте `HomePrint-<версия>-setup.exe`.
2. Windows покажет «Windows защитил ваш компьютер»: установщик не подписан покупным сертификатом. Нажмите «Подробнее» → «Выполнить в любом случае».
3. HomePrint ставится для вашего пользователя, права администратора не нужны.

Переносная версия `HomePrint-<версия>-portable.exe` работает без установки, но сама не обновляется.

## Обновления

Установленный HomePrint сам заглядывает сюда, скачивает новую версию и предлагает перезапуститься. Если не перезапускать, обновление встанет при закрытии программы. Каждое обновление подписано, и HomePrint ставит только обновления с верной подписью. Выключить самостоятельную установку можно в настройках, в разделе «О программе».

## Что нужно

- Windows 10 или 11, 64 бита.
- Принтер по сети (IPP Everywhere / AirPrint) или с драйвером Windows.
- Сканер с драйвером Windows (WIA) или по сети (eSCL).

Проверено на Brother DCP-T420W. Другие принтеры и сканеры работают через те же стандартные пути, но на них HomePrint не проверялся.

## Ваши данные

Сканы, работы и настройки хранятся только на вашем компьютере. В интернет HomePrint обращается только сюда, за обновлениями.
